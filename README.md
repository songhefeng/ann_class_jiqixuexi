# ann_class_jiqixuexi
项目简介
本项目基于 Python + PyTorch 搭建三层全连接人工神经网络（ANN），对威斯康星乳腺癌数据集 (WDBC) 完成良恶性肿瘤二分类任务。项目完整实现数据预处理、模型搭建、训练调优、多维度性能评估、可视化、模型可解释性分析全流程，可作为机器学习课程大作业、神经网络入门实践案例。

四、数据集说明
数据集名称：威斯康星乳腺癌数据集（WDBC）
数据规模：共 569 条样本，30 维细胞核形态特征
标签定义
B (Benign)：良性肿瘤 → 映射为数值 0
M (Malignant)：恶性肿瘤 → 映射为数值 1
样本分布：良性样本 357 条，恶性样本 212 条，样本整体分布均衡，适合二分类实验。
数据路径：代码默认读取路径 D:\data.csv，请根据本地文件位置自行修改路径。

六、神经网络结构
采用浅层全连接人工神经网络，结构简洁、轻量化、不易过拟合：
plaintext
输入层(30个神经元) → 隐藏层1(16个神经元, ReLU) → 隐藏层2(8个神经元, ReLU) → 输出层(1个神经元, Sigmoid)
激活函数：隐藏层使用 ReLU，输出层使用 Sigmoid
损失函数：二分类交叉熵损失 BCELoss
优化器：Adam，初始学习率 0.001
训练迭代轮数：100 轮

八、实验结果与分析
1. 训练结果
模型共训练 100 轮，训练损失持续平稳下降，后期趋于平缓，模型完全收敛，未出现梯度消失、梯度爆炸等异常问题。
2. 核心分类指标
测试集整体准确率：95.61%
良性样本：精确率 96%，召回率 97%，F1 分数 97%
恶性样本：精确率 95%，召回率 93%，F1 分数 94%
3. 可视化结果说明
特征相关性热力图：肿瘤尺寸类特征存在强正相关性，数据集存在明显特征冗余；
混淆矩阵：绝大多数样本分类正确，仅少量恶性样本被误判为良性；
训练损失曲线：训练过程稳定，100 轮迭代后模型收敛；
ROC 曲线：AUC ≈ 0.997，模型区分良恶性样本能力极强；
PR 曲线：曲线高位稳定，模型鲁棒性优秀；
SHAP 蜂群图（船形图）+ 特征重要性图：实现黑箱模型解释，明确细胞形态类特征为核心分类依据，分析结果符合医学规律。
九、模型现存问题与优化方向
1. 现存不足
恶性样本召回率略低，存在少量漏诊风险，无法完全满足医疗高可靠性要求；
数据集存在大量高相关冗余特征，增加模型运算量；
网络超参数仅人工调试，未进行系统化寻优；
网络未添加正则化，扩充数据后存在过拟合隐患。
2. 后续优化方案
数据层面：采用 SMOTE 过采样，平衡正负样本，提升恶性样本识别率；
特征工程：基于相关性分析筛选冗余特征，或使用 PCA 降维；
模型调优：使用网格搜索 / 随机搜索优化学习率、神经元数量等超参数；
网络优化：添加 Dropout、L2 正则化，抑制过拟合；
算法融合：结合 SVM、随机森林等模型，进一步提升分类稳定性。
