# ann_class_jiqixuexi
本项目使用 Python 语言结合 PyTorch 深度学习框架，搭建三层全连接人工神经网络，完成威斯康星乳腺癌数据集的良恶性肿瘤二分类任务。项目完整实现数据预处理、神经网络搭建、模型训练、性能评估、多维度可视化以及模型可解释性分析全流程，可作为机器学习课程实践作业与神经网络入门案例。
项目所用数据集为公开医学数据集，总计 569 条样本，包含 30 维细胞核形态特征，其中良性肿瘤样本 357 条，恶性肿瘤样本 212 条，整体样本分布较为均衡。实验首先对原始数据进行处理，将字符标签转换为模型可识别的数字标签，并按照八比二的比例分层划分为训练集与测试集。为消除不同特征数值范围带来的影响，对全部特征执行标准化操作，同时通过特征相关性热力图分析特征之间的关联关系，识别数据中存在的冗余特征。
本次搭建的人工神经网络采用经典浅层结构，依次为 30 维输入层、16 神经元隐藏层、8 神经元隐藏层以及单神经元输出层。隐藏层选用 ReLU 激活函数提升非线性拟合能力，输出层使用 Sigmoid 激活函数输出分类概率，搭配二分类交叉熵损失函数与 Adam 优化器开展模型训练，整体迭代轮数设置为 100 轮。
模型训练完成后，从多个维度开展性能测试与结果分析。模型在测试集上整体分类准确率达到 95.61%，良性样本与恶性样本的精确率、召回率、F1 分数均保持在较高水平。通过训练损失曲线可以看出，模型损失值持续平稳下降，训练后期逐步趋于稳定，完成正常收敛，未出现梯度消失、梯度爆炸等异常问题。混淆矩阵结果显示，绝大部分样本分类正确，仅存在少量恶性样本被误判为良性的情况。
为进一步评估模型综合能力，本项目绘制 ROC 曲线与精确率 - 召回曲线，模型 AUC 值接近 1，两条曲线均表现稳定，证明模型区分正负样本的能力强、鲁棒性良好。针对神经网络黑箱特性，项目引入 SHAP 算法完成特征贡献分析，通过蜂群图与特征重要性图明确各类特征对分类结果的影响大小与作用方向，分析结论与医学特征规律保持一致，实现了模型的可解释性。
对比逻辑回归、K 近邻等传统机器学习算法，本次设计的浅层人工神经网络在分类精度和运行效率上更具优势。同时项目也总结出当前存在的不足：恶性样本存在少量漏诊风险，数据集存在特征冗余，模型超参数仅依靠人工调试，网络未添加正则化策略。针对以上问题，后续可以采用样本增强、特征筛选、超参数寻优、添加正则项、多模型融合等方式持续优化模型。
